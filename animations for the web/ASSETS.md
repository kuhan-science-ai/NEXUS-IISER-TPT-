# Animation assets

Original filenames are kept in this folder. Runtime copies are listed with the source they match.

## Nuke animation

- `nuke_explosion.webm` — source clip used by the History clear animation.
- `nuke_explosion.png` and `nuke_explosion.gif` — image previews of the nuke animation.
- `nuke_animation.js` — existing JavaScript animation implementation.
- `Pasted text.txt` — JavaScript reference supplied in chat; saved as received.
- `generate_nuke.py` and `generate_nuke_v2.py` — source generators.

Runtime copy: `../frontend/public/nuke-history-clear.webm` is an exact copy of `nuke_explosion.webm`.

## Explosion animation

- `explosion.webm`, `explosion.png`, and `explosion.gif` — explosion animation files and previews.
- `explosion.js` — JavaScript implementation.
- `generate_explosion.py` — source generator.

Runtime copies: `../frontend/public/profile-launch-fireball.webm` is an exact copy of `explosion.webm`. `../frontend/public/profile-launch-explosion.webm` is the classic profile launch effect.

## QOTD card artwork

- `quiz_card_cleaned.png` — supplied Question of the Day card artwork.

Runtime copy: `../frontend/public/quiz_card_cleaned.png` is the image used by the shared QOTD template.

`index.html` is the animation preview page. `README.md` contains the folder notes.
