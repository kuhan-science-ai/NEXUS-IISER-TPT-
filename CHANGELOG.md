## [0.1.0] - Foundation, Core Architecture & Subsystems
- **Project Structure**: Established modular layout (`frontend/`, `backend/`, `database/`, `storage/`, `tests/`, `docs/`, `scripts/`).
- **Database Architecture**: Implemented 36 SQLAlchemy 2.0 ORM models covering Users, Profiles, Social, Messages, Academics, Forums, Calendar, Notifications, Campus, AI, and Audit Logs. Generated initial Alembic migration (`database/migrations/versions/2bc2c2624ca2_initial_schema.py`).
- **Security & Authentication**: Bcrypt password hashing, JWT access/refresh token handling, login sliding-window rate limiting, role-based backend authorization (`Student`, `Moderator`, `Administrator`), and 1-click dev demo accounts.
- **Storage Subsystem**: Created file storage abstraction supporting avatar, banner, academic PDF, and document uploads with MIME type filtering and size limit validation.
- **Permanent Messaging & Real-Time WebSockets**: Permanent database storage for conversations, messages, reactions, read receipts, and replies. Bidirectional WebSocket connection manager with instant delivery, typing indicators, and presence.
- **AI Orchestration Framework**: Complete 14-stage request-processing pipeline (Validation, Context, Routing, Tool Registry, Safety Permissions, Streaming, Persistence). Built `MockAIProvider` with deterministic responses, simulated delays, and safety confirmation gates without external AI calls.
- **Local LaTeX Mathematical Rendering**: Integrated locally bundled KaTeX (zero CDN reliance) with `MathRenderer` component supporting inline `$math$` and display `$$math$$` notation across Forums, Messages, and the Scientific Document Editor.
- **Academic & Campus Systems**: Built REST APIs and data access for Academic Repository, Course Catalogue, Discussion Forums, Campus Pulse, Notifications, Calendar, Tasks, and QOTD/AOTD.
- **Automated Verification**: Created and passed 6 comprehensive test suites covering auth, profiles, storage, friends & blocking, messaging, and AI orchestration. Built frontend with Vite + React 18 + TypeScript with zero compilation errors.
