NEXUS assistant companion animation workflow
============================================

Runtime behavior
----------------
`frontend/src/components/AssistantCompanionPet.tsx` starts one random action
clip when the companion appears. Actions are `ani-1.webm`, `ani-2.webm`, and
`ani-3.webm`; the third is the former one-shot default action. When an action
ends, the pet resumes `default-ani.webm`, the new idle animation, from its first
frame. Clicking during idle chooses and plays a random action, then returns to
idle. The idle WebM contains a trimmed forward-and-back cycle and uses the
video loop flag, so its endpoints meet without showing the source fade to black.

Asset preparation
-----------------
Run `python scripts/prepare_assistant_companion_animations.py` from the
repository root. The conversion environment needs ffmpeg/ffprobe, Pillow,
numpy, rembg, and its cached `u2netp` model. These packages are not
frontend runtime dependencies.

The three action sources (`ani-1.mov`, `ani-2.mov`, and `ani-3.mov`) are
3840x2160 at 30 fps. Each is cropped to 1800x1850 at x=1020,y=200, scaled to
900x925, and matted with `u2netp`. The script measures the character's
alpha bounds across every frame, adds transparent padding, and writes the
cropped VP9 alpha assets to `frontend/public/assistants/waifu-2/`. The broader
source crop captures arm and leg movement outside the previous frame edges;
the floating companion's 210x310 interaction box stays the same size.

The idle source `default ani.mp4` is a 614x994 video with a solid navy backdrop.
The script samples that backdrop, keys and unmixes its edges, trims before the
source fade to black at 8.6 seconds, and appends the reversed frames to create
a seamless forward-and-back cycle. The output replaces `default-ani.webm`.

Verification
------------
Check each output with ffprobe for the `alpha_mode=1` tag. For visual alpha
inspection, decode with libvpx (`-c:v libvpx-vp9`) and composite a frame on a
dark background; FFmpeg's native VP9 decoder may display an opaque frame even
when the WebM alpha is valid. Inspect reaction clips at their widest poses and
check hands, ears, and shoes against the transparent crop boundaries.

Run `npm run build` in `frontend/` before deployment. The page hides the idle
video while a reaction plays and cross-fades back to it when that action ends.
